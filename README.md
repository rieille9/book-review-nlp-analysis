# NLP Book Review Analysis & Rating Prediction

This project explores Natural Language Processing techniques on a large-scale dataset of book reviews (~357k reviews).

The project includes:
- Rating prediction using machine learning and deep learning models
- Topic modeling and sentiment analysis
- NLP-based recommendation systems
- Comparative evaluation of TF-IDF, LSTM and Transformer-based models

## Tech Stack

- Python
- Scikit-learn
- TensorFlow / Keras
- HuggingFace Transformers
- BERTopic
- Sentence Transformers
- Pandas / NumPy
- Matplotlib / Seaborn

## NLP Approaches

### Classical NLP
- Bag of Words
- TF-IDF
- Logistic Regression
- Hyperparameter tuning with GridSearchCV

### Deep Learning
- Bidirectional LSTM
- Word Embeddings
- Sequence modeling

### Transformer-based NLP
- DistilBERT embeddings
- Sentence Transformers

### Topic Modeling
- BERTopic
- UMAP
- HDBSCAN clustering
